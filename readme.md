# Nom

Formulaire Entreprise

# Description

Le projet suit le CRUD, il peut mettre en place des formulaires et des pages de traitement PHP pour gérer la table employes de la base de donnée entreprise

C.R.U.D :

Create , formulaire pour créer un nouvel employé
Rread , page qui liste tous les employés
Update , formulaire pour mettre à jour un employé
Ddelete , formulaire pour supprimer un employé

# Installation

Bootswatch a été utilisé pour mettre en forme le formulaire.
Sinon PHP, HTML, CSS

# Utilisation

Comme dit au dessus, grâce à ce formulaire on est censé pouvoir editer/ajouter/suppr des employés dans la base de donnée sans erreur
